🌾 KrishiBondhu AI

«AI-powered agricultural assistant for smarter farming decisions.»

KrishiBondhu AI is an intelligent agriculture assistant designed to help farmers and agricultural users make better decisions using Artificial Intelligence, Machine Learning, weather information, crop disease detection, and fertilizer recommendations.

The goal of KrishiBondhu AI is to bring useful agricultural intelligence into one simple and accessible platform.

---

🚀 Features

🤖 AI Chat Assistant

Ask agriculture-related questions and get AI-powered responses.

- Crop-related questions
- Farming guidance
- General agricultural assistance
- Natural language interaction

🌿 Plant Disease Detection

Identify possible crop diseases from plant images using AI/Computer Vision.

Planned/Integrated capabilities:

- Image-based disease detection
- Disease identification
- Basic treatment/prevention suggestions

🌦️ Weather Information

Provides weather-related information that can help farmers make better decisions.

Potential use cases:

- Rainfall awareness
- Temperature information
- Farming activity planning
- Weather-based crop management

🧪 Fertilizer Recommendation

Helps recommend suitable fertilizers based on agricultural inputs and crop requirements.

The system can be extended to consider:

- Crop type
- Soil conditions
- NPK values
- Environmental conditions
- Farming requirements

⚙️ Installation

1. Clone the repository

git clone https://github.com/Codedbyriyad/KrishiBondhu_AI.git

2. Navigate to the project

cd KrishiBondhu_AI

3. Install dependencies

Follow the installation instructions inside the respective "frontend" and "backend" directories.

For example:

cd frontend
npm install

Then start the development server:

npm run dev

---

🔐 Environment Variables

Create a ".env" file for required API keys and configuration.

Example:

AI_API_KEY=your_api_key_here
WEATHER_API_KEY=your_weather_api_key_here

Never commit API keys or other secrets to GitHub.

🧠 Core Modules

1. AI Chat

The AI assistant acts as a digital agricultural companion that can answer farming-related questions and provide general guidance.

2. Disease Detection

Users can provide a crop/plant image, and the computer vision system analyzes it to identify potential diseases.

3. Weather

Weather information can be used alongside agricultural knowledge to help users plan farming activities.

4. Fertilizer Recommendation

The fertilizer module is designed to provide data-driven recommendations based on crop and soil-related information.
